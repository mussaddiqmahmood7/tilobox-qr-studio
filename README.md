# TiloBox QR Studio

> **The Designer\'s Studio for Custom-Shaped & Geometric QR Codes**  
> An agency-grade, client-side parametric QR generator running 100% in-browser with **zero required environment variables** and **zero external database connections**. Part of the official [TiloBox Ecosystem](https://tilobox.com).

---

## ✨ Features

- 🎨 **100% Client-Side & Private**: All QR codes generate instantly inside your browser using mathematical SVG algorithms. No telemetry pings, no accounts, and no data tracking.
- 🏢 **1-Click Business Presets**:
  - 🍽️ **Restaurant Digital Menu**: High-contrast, scannable table menu links.
  - 💇 **Barber & Salon Booking**: Fast appointment booking cards.
  - 🚖 **Taxi & Fleet Dispatch**: Direct WhatsApp and phone call dispatch links.
  - 📶 **Guest Wi-Fi Card**: Camera-scan instant Wi-Fi network connection modal.
  - 💼 **vCard Digital Business Card**: One-tap contact save format (vCard 3.0).
- 🖼️ **Center Logo & Branding Embed**: Upload PNG, SVG, or JPEG logos with protective circular/rounded masking and automatic high error correction fail-safe.
- 🎭 **Curated TiloBox Themes**: Soft Slate, Cyberpunk Slate, Classic Obsidian, Paper Light, plus custom hex pickers.
- 📦 **Pro Export Suite**:
  - **Vector SVG**: Lossless vector graphic for menus, laser cutting, and billboards.
  - **High-Res PNG**: Standard (1024px), 2K (2048px), and 4K Print-Ready (4096px).
  - **Printable 4x6 Display Tent Card**: Print-ready CSS layout designed for tabletop cardstock stands.

---

## 🚀 Getting Started

### Zero-Config Local Development
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser. **No `.env` file or API keys are required.**

### Production Build
```bash
npm run build
npm run start
```
